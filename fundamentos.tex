\begin{contentbox}{label=Decisiones con \texttt{if}}
    Ejecutar sentencias que solo deben ocurrir al cumplirse la \mintinline{python}|<condición>| (\alert{expresión booleana}):
\begin{minted}{python}
if <condición>:
    <sentencias condicionadas>
\end{minted}

    Ejecutar sentencias que solo deben ocurrir al cumplirse una condición, y otras en caso que no:
\begin{minted}{python}
if <condición>:
    <sentencias condicionadas>
else:
    <sentencias alternativas>
\end{minted}

    % Ejecutar sentencias que solo deben ocurrir al cumplirse una condición, otras en caso de que no se cumpla la primera condición, pero si una segunda condición\footnote{Tantas condiciones secundarias (\mintinline{python}|elif|) como se necesite.}, y otras en caso de que no se cumpla la primera ni la segunda:
    Ejecutar diferentes sentencias, según qué condición sí se cumpla\footnote{Tantas condiciones secundarias (\mintinline{python}|elif|) como se necesite.}:
\begin{minted}{python}
if <condición 1>:
    <sentencias condicionadas 1>
elif <condición 2>:
    <sentencias condicionadas 2>
else:
    <sentencias alternativas>
\end{minted}
\end{contentbox}

\begin{contentbox}{label=Bloques de decisiones}
    Cada secuencia \mintinline{python}|if|, \mintinline{python}|if-else| o \mintinline{python}|if-elif-else| es un bloque independiente.
    
    Dentro de un mismo bloque se ejecutarán las sentencias condicionadas a la primera condición válida comprobada.
    
    Si existieran 2 bloques de decisión consecutivos se ejecutarán las sentencias condicionadas a la primera condición válida para cada bloque de manera independiente.
\end{contentbox}

\begin{contentbox}{label=Ciclos con \texttt{while}}
    Realizar una repetición condicionada de sentencias: 
\begin{minted}{python}
while <condición>:
    <sentencias_a_repetir>
\end{minted}

    Donde \mintinline{python}|<condición>| es una \alert{expresión booleana} y \mintinline{python}|<sentencias_a_repetir>| (indentada con respecto a \mintinline{python}|while|) es la secuencia de instrucciones a repetir.
    
    A través de este bloque, se asegura la ejecución de las \mintinline{python}|<sentencias_a_repetir>| mientras se cumpla la \mintinline{python}|condición| señalada.
    
    Se puede repetir cualquier sentencia, incluyendo otros ciclos.
\end{contentbox}

\begin{contentbox}{label=Función \mintinline{python}|range|}
    Generación de secuencias numéricas:
    \begin{itemize}
        \item \mintinline{python}|range(stop)| genera números de 0 a \texttt{stop-1}.
        \item \mintinline{python}|range(start, stop, d)| genera números desde \texttt{start} hasta \texttt{stop-1}, con distancia de \texttt{d} entre ellos.
    \end{itemize}
    
    Nótese que \mintinline{python}|range| no es una lista, pero puede convertirse a una mediante \mintinline{python}|list(range(n))|.
\end{contentbox}

\begin{contentbox}{label=Ciclos con \texttt{for}}
    Repite la acción por cada elemento de la secuencia:
\begin{minted}{python}
for elemento in secuencia:
    acciones_a_repetir
\end{minted}
    
    La variable \mintinline{python}|elemento| es definida en el \mintinline{python}|for| y su valor es cada elemento de la secuencia en orden.
    
    Entre las secuencias, se incluyen \mintinline{python}|list|, \mintinline{python}|str|, \mintinline{python}|range|, archivos, etc.
\end{contentbox}

\begin{contentbox}{label=Banderas (\textit{Flags})}
    % Parte de la \mintinline{python}|<condición>| puede ser una variable booleana: esta indica si se debe continuar o no, según qué ocurra en el ciclo:
    Se llaman así a variables booleanas que se usan como parte de una \mintinline{python}|<condición>|:
\begin{minted}{python}
i = 1
keep_going = True
while keep_going and i <= 5:
    if i % 2 == 0:
        keep_going = False
    i += 1
\end{minted}

    % Haciendo uso de decisiones (\mintinline{python}|if|) y de una bandera (\mintinline{python}|keep_going|), se puede verificar si se cumple una condición adicional bajo la cual detener el ciclo antes de que el iterador \mintinline{python}|i| llegue a su límite.
    Con esto, se puede detener el ciclo antes de que el iterador \mintinline{python}|i| llegue a su límite.
\end{contentbox}

\begin{contentbox}{label=\textit{Slices} y Copias}
    % Pueden accederse \alert{cortes} (\textit{slices}) de una secuencia como una lista o string mediante la \alert{notación slice}. Su notación básica es
    Un \alert{corte} (\textit{slice}) de una secuencia es una \textit{subsecuencia} de la original:
    \begin{center}
        \mintinline{python}|objeto[a:b:c]|
    \end{center}
    Inicia en \mintinline{python}|a|, llega a \mintinline{python}|b| (sin incluirlo) y salta de \mintinline{python}|c| en \mintinline{python}|c| (entero positivo o negativo).
    
    Esta notación tiene las siguientes variaciones:
    \begin{itemize}
        \item Si se omite \mintinline{python}|a| (pero no \mintinline{python}|:|), inicia desde el comienzo.
        \item Si se omite \mintinline{python}|b| (pero no \mintinline{python}|:|), llega hasta el final.
        \item Si se omite \mintinline{python}|c| (incluyendo o no \mintinline{python}|:|), se asume 1.
    \end{itemize}
\end{contentbox}

\begin{contentbox}{label=Índices}
    Los índices de un \textit{string} o lista de largo $n$ parten en 0 y llegan a $n-1$, o parten en -1 (final) y llegan a $-n$ (inicio).
\end{contentbox}

\begin{contentbox}{label=Largo de una Secuencia}
    El largo de la secuencia \mintinline{python}|seq| se obtiene mediante la función nativa \mintinline{python}|len(seq)|. Se entiende por ``largo'' de una secuencia como el total de elementos que hay en esta.
    
    En el caso de una lista, si tiene como elemento otra lista, este elemento sigue contando como uno solo.
\end{contentbox}

\begin{contentbox}{label=String a Lista y Viceversa}
    \begin{itemize}
        \item \mintinline{python}|s.split(sep)| separa el string utilizando \texttt{sep} como separador y retorna una lista cuyos elementos son los fragmentos del string.
        \item \mintinline{python}|sep.join(lista)| une los elementos de \texttt{lista}, separados por \texttt{sep}, en un único string. Solo funciona si los elementos de la lista son strings.
    \end{itemize}
\end{contentbox}
